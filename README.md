# Trending Topics Analyzer

A news trend analysis system using HashMap and Min Heap to identify popular and trending topics from the HuffPost News Dataset.

## Live Demo

[Open Trending Topics Analyzer](https://trending-topics-analyzer-dha3farpr5ciu7mdyox264.streamlit.app)

## Technologies Used

- Python
- Streamlit
- Pandas
- HashMap
- Min Heap
- HuffPost News Category Dataset
- Hugging Face

## Features

- Top-K frequent words
- Trending topic detection
- Word search over time
- Category-wise analysis
- Heap vs Sort performance comparison
